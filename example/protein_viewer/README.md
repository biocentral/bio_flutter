# Example

Run `fvm flutter pub get` here, then `fvm flutter run -d linux` or
`fvm flutter run -d chrome`. The parent `.fvmrc` selects the SDK.

The sequence chips and structure viewer share selection when **Link sequence
selection** is enabled. Turn it off to use the viewer's internal selection.
Annotations are independent purple highlights; selection and hover take visual
precedence over them.

See [platform setup](../../doc/protein_viewer/platforms.md) for macOS and Windows configuration.
The example uses the public package entry point and has no direct Scene dependency.
